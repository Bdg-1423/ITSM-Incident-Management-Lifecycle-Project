# These represent the standard lifecycle of a healthy, active ticket:

• New ➡️ In Progress: Incoming tickets move directly into active work.

• In Progress 🔄 On Hold: Work can be temporarily paused and resumed.

• On Hold 🔄 Resolved: A paused ticket can move directly to a resolved status once the blocker is cleared, or vice versa if a resolution needs adjustment.

• Resolved ➡️ In Progress: If a resolution is rejected or requires further work, the ticket can be reopened back to active development.

• Resolved ➡️ Closed: The final standard step when the issue is fully addressed and finalized.

🔸 Canceled Routes (Dashed Lines)
These represent the paths taken when a ticket is aborted or scrapped at various stages:

• New ➡️ Canceled: A newly created ticket can be canceled immediately before any work begins.

• In Progress ➡️ Canceled: Active tickets can be canceled if they are deemed no longer necessary.

• Resolved ➡️ Canceled: Even after a resolution is reached, a ticket can still be canceled instead of being permanently closed.
